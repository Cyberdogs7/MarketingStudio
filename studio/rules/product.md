# Product staging contract

The canonical `product_description` (from Gate 1) is a VERBATIM contract. It
must cover: shape, material, color, hand-relative size ("palm-sized, ~12 cm tall"
— never object comparisons), mechanism anatomy (which part is where, what moves,
where output exits), absent-feature negatives ("cordless, no buttons, no digital
display"), label handling, and one honest imperfection.

## Angle lock (when a product photo exists)

The product shows only the visible front-facing side from the reference photo.
It keeps this same visible angle in every shot it appears in. Do not rotate,
spin, flip, or reveal unseen sides. Switch angles only by a hard cut between
shots, never by continuous rotation. Never invent back labels, side panels, or
internal components. Product label, color, shape and logo identical across all
appearances.

## Realistic scale (mandatory)

The product MUST appear at its real-world physical size relative to the
creator's hand, fingers, and body. Never enlarge the product so the label is
readable — move the camera closer instead. Size hand-relative plus exact cm
("palm-sized, fits entirely in one hand, ~15 cm tall").

## Exactly one hero product

Exactly ONE unit of the product exists in every shot where it appears — never a
duplicate, never a look-alike clone on a shelf or counter. State "exactly one
[product] in frame". If look-alike shapes exist in the scene, remove them or
state the product is the only [shape/color] object in frame.

## Placement per shot

The product is visible ONLY if the shot's action requires it:

- Show / present / hold-and-present beat -> fully visible held in one hand
- Open / unscrew / pump / apply / interact beat -> fully visible
- Reaction with product in hand -> fully visible
- Pure setup / problem moment / talking-head hook -> hidden or absent

Hidden = fully inside a closed bag/box/pocket, OR held cleanly in one hand
(vertical, full grip), OR absent from frame. NEVER partial, never half-sticking
out of a bag, never balancing awkwardly, never floating.

## Label and wordmark

- With a real product photo, the label keeps its real text via the reference
  image + angle lock — never redraw, restyle, or re-letter it.
- No legible text on any OTHER prop (receipts, screens, price tags render as
  gibberish) — printed sides face away or are too small to read.
- No real brands beyond the product's own label. Garment lettering is fictional,
  big, and bold (small lettering renders as gibberish).

## Safe interaction verbs

- Glass / hard plastic / metal: rests on palm, holds lightly, cradles,
  presents, taps gently. Forbidden: squeeze, crush, deform.
- Soft tube: holds, gently squeezes, presses lightly. Forbidden: crushes,
  wrings.
- Cardboard box: holds from sides, presents front face. Forbidden: crushes,
  tears.
- Any product: holds, shows, lifts, presents, points at. Forbidden: throws,
  catches, juggles, spins, drops.
When unsure -> hold-and-present only.

## Mechanism anatomy

Lock the mechanism once from the description (e.g. "pump on TOP, pressed
straight DOWN with two fingers, product exits the BOTTOM spout"). Every shot
follows that exact anatomy — never invent geometry. Sequence: opening mechanic
(uncap / unscrew / press pump / flip top) BEFORE any contents exit. Maximum one
product state change per shot; removed caps/lids disappear and are never
described again; a cap is ON or OFF, never both.

## Absent features

If the selling point is an ABSENCE (cordless, no buttons, battery-free,
sugar-free), write the absence visually in BOTH the slot description AND a
negative tail ("no power cord, no power button, no charging port, no digital
display") — image models hallucinate the default affordance back in.
